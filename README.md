2. [repolens](https://github.com/anirudw/repolens.git)

    A developer assisting CLI tool to map out the core architectural signals in a repository. Repolens uses treesitter to create an AST of the codebase and parses the coupling and implementational dependency in real code repos. Featured on [StrictSeal's developer tools worth knowing - April 2026](https://strictseal.com/blog/articles/developer-tools-worth-knowing-april-2026)
